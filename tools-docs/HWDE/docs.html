HackerOS Wayland Desktop Environment

Powłoka i kompozytor jednego systemu.

HWDE to natywne środowisko graficzne HackerOS: powłoka starthwde (SolidJS + Rust/Tauri v2) i kompozytor Wayland/XWayland comphwde (Smithay 0.7), połączone własnym, minimalnym protokołem IPC po gnieździe uniksowym — bez zbędnych zależności, bez telemetrii, gotowe do pracy offline.

Instalacja i budowanie

Wymagania: Rust ≥ 1.80 (rustup), Node.js ≥ 20, standardowe zależności Tauri v2 dla Linuksa oraz biblioteki Wayland/wejścia.

1

Zbuduj wszystko

Kompiluje starthwde i comphwde w trybie release oraz builduje frontend Vite.

2

Zainstaluj

Kopiuje binaria do /usr/bin, plik sesji oraz domyślną tapetę.

3

Uruchom sesję

Wybierz „HWDE” na ekranie logowania (SDDM) albo uruchom z TTY.

bash 
make build          # wszystko, tryb release
make shell           # tylko starthwde (frontend + backend Tauri)
make compositor       # tylko comphwde
make dev              # powłoka w oknie, bez kompozytora (najszybsza pętla developerska)
sudo ./install.hl     # instalacja do /usr/bin, plik sesji, domyślna tapeta
starthwde — tryby uruchomienia 
starthwde              pełna sesja graficzna (spawnuje i nadzoruje comphwde)
starthwde dev           powłoka jako zwykłe okno, bez kompozytora
starthwde app <nazwa>   pojedyncza aplikacja HWDE bez chrome powłoki
                        (np. settings, clipboard, about, emoji)
Jak to jest zbudowane

Powłoka, kompozytor i most między nimi

Zamiast wlr-foreign-toplevel-management HWDE używa własnego, prostego protokołu NDJSON po gnieździe uniksowym — mniej zależności po stronie powłoki, kosztem braku wsparcia dla zewnętrznych pasków zadań.

starthwde

SolidJS + Rust/Tauri v2. Powłoka, launcher, ustawienia, panel Wi-Fi/Bluetooth/audio, sklep z ikonami.

⇄ hwde-ipc (NDJSON / unix socket)

comphwde

Smithay 0.7. Wayland/XWayland, kafelkowanie, wieloprzestrzenność, warstwy wlr-layer-shell, dekoracje.

Bezpieczeństwo gniazda

Katalog 0700, gniazdo 0600, a każde połączenie jest dodatkowo weryfikowane przez SO_PEERCRED — odrzucane, jeśli UID rozmówcy nie zgadza się z UID sesji.

◆

Bezpiecznik awaryjny

Ctrl+Alt+Shift+Esc zaszyty na sztywno w kompozytorze — działa nawet gdy wtyczka „zamiennika powłoki” przechwyci cały interfejs.

Pliki konfiguracyjne

compositor.toml i settings.hk

Oba pliki żyją pod ~/.config/HWDE/ i są zapisywane z sensownymi wartościami domyślnymi przy pierwszym uruchomieniu.

~/.config/HWDE/compositor.toml
workspace_count = 4
gaps = 8
border_width = 2
master_ratio = 0.55

[[keybindings]]
mods = ["super"]
key = "Return"
action = "spawn:kitty"

[[keybindings]]
mods = ["super", "shift"]
key = "f"
action = "toggle_floating"   # nowość v0.2
~/.config/HWDE/settings.hk
theme = dark
wallpaper = /usr/share/wallpapers/HackerOS-Wallpapers/Wallpaper23.png
icon_theme = Breeze
launcher_icon = /usr/share/HackerOS/ICONS/HackerOS.png
language = pl

Jeśli nadal widzisz pusty wynik

To już nie „cichy” błąd — prawdziwy problem sieciowy (brak połączenia, TLS, API offline) zwróci teraz czytelny komunikat błędu w panelu zamiast pustej listy. Sprawdź połączenie internetowe lub spróbuj drugiego źródła (KDE Store / GNOME-Look).

Pytania i odpowiedzi

FAQ

Bo powłoka i kompozytor są tym samym projektem — własny protokół IPC daje ten sam praktyczny efekt (wspólna lista okien w tasku) przy znacznie mniejszej powierzchni zależności, kosztem niekompatybilności z zewnętrznymi paskami zadań.

Z punktu widzenia Space obie operacje wyglądają identycznie (odmapowanie okna), ale są śledzone osobno — żeby zminimalizowane okno na przestrzeni w tle nie „ożyło” przypadkiem przy przełączeniu z powrotem.

Backend backend_drm.rs istnieje za flagą drm-experimental, ale wciąż nie jest podpięty do main — wymaga dopracowania na prawdziwym sprzęcie (atomic KMS + pętla renderowania). Domyślnie działa backend winit.

Super+Shift+F wyklucza pojedyncze okno z kafelkowania master-stack na jego przestrzeni, bez wyłączania kafelkowania dla pozostałych okien — przydatne dla dialogów czy odtwarzaczy picture-in-picture.

W repozytorium na GitHubie (link w prawym górnym rogu tej strony) — sekcja Issues.
